# Building Menu addons -> Community Tilepack sheets (generated)

Generated by `pz_craft_loops/map_buildmenu_addons.py`. The three B41 Building Menu addons are run in a Lua sandbox against a mock Building Menu API (all sandbox options on), so every menu entry is listed with its real sprites and recipe. Built status comes from `zomboid/TILE_COVERAGE_INVENTORY.csv` (rerun `tile_coverage_inventory.py` first).

- **built**: every Community sprite of the entry is already used by a buildable.
- **partly built** / **not built**: some / none of its sprites are. These are the mass-conversion queue.
- Full rows (sprites per face, options): `ADDON_SPRITE_MAP.csv`. Recipes: `ADDON_RECIPES.json`.
