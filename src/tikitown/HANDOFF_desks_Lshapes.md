## KEY LESSONS (for resuming)
- Build from the USER CATALOG + verified geometry; do NOT use the game .tiles SpriteGridPos (unreliable on this sheet).
- Each facing's 2x1 axis is fixed (N/S horizontal, E/W vertical). Within-pair order and improv tiles must be confirmed in-game per rotation - derive, deploy, iterate one cell at a time.
- Corners: only 2 real corner sprites (3=E/S, 11=N/W). The other 2 L rotations have NO matching corner -> must improvise with a non-corner tile that happens to read as a corner, OR accept two end caps / drawers-on-short-side. This is the unsolved part.
